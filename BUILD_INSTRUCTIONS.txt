TEAL EXPO VISITOR CAPTURE — BUILD / INSTALL NOTES
==================================================

APP VERSION
- Version name: 2.0
- Android package: com.teal.expo
- Minimum Android version: Android 8.0 (API 26)
- Offline-first; no server/cloud API is used at runtime.

GET THE APK
1. Open https://github.com/Chandrasekharsahu17/Teal-Visitor-App/actions
2. Open the latest successful "Build TEAL Expo APK" run.
3. In Artifacts, download "TEAL-Expo-Visitor-Capture-APK".
4. Extract the ZIP and install app-debug.apk on the Android device.
5. If Android requests permission, allow your file manager/browser to install this APK.

BACKUP BEFORE REINSTALLING
- Open Export Data and create a JSON backup.
- Keep the backup outside the app/phone before uninstalling or switching devices.
- JSON import restores the record fields and photos.

FEATURES
- Four-step visitor-registration workflow with business-card capture first.
- On-device ML Kit OCR with suggested name, company, designation, phone, email,
  alternate phone, website, LinkedIn/profile and labelled address.
- All original recognized OCR text is retained with each record for verification.
- Required fields: visitor name, company, designation, phone number.
- Optional contact data, interests, TEAL representative, meeting notes and visitor photo.
- Local search, details view, edit/delete, Excel with embedded photos, JSON backup/import.
- Data remains on the device; no backend or runtime cloud service.

SOURCE FILES
- UI: app/src/main/assets/index.html
- Android native bridge: app/src/main/java/com/teal/expo/MainActivity.java
- App manifest: app/src/main/AndroidManifest.xml
- Build: app/build.gradle and .github/workflows/android.yml

TEST BEFORE THE EVENT
Create several dummy visitor records. Verify OCR against the original card, save/reopen,
edit, camera/gallery, Excel export, photo embedding, JSON backup/restore and offline use.
OCR may misread text; check the suggestions before saving.
